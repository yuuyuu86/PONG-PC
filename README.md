# PONG! for PC（Mac / Windows）

同じ部屋のPC 2台をつないで遊ぶ、白黒落書き風の1対1スポーツゲーム集。
Flutter で作ったデスクトップアプリで、**Mac（Apple シリコン + Intel のユニバーサル）** と **Windows（x64）** で動きます。
Mac 同士・Windows 同士・Mac と Windows の組み合わせで対戦できます。

デザインはスマホ版 PONG! と共通です（`lib/ui/doodle.dart`・`lib/ui/widgets.dart`・`lib/avatar/` をスマホ版からそのまま使用）。
紙・墨・鉛筆の色、Yomogi フォント、手描きの枠と影、●○× の状態表示、着せ替えできる棒人間のアバター、ロゴ。

| タイトル | 特徴 | 勝敗 |
| --- | --- | --- |
| バレー | 高いネット、高いジャンプ。自陣で3回まで触れる（レシーブ→トス→スパイク） | 5点先取・得点ごとにサーブ交代 |
| バドミントン | 速く飛び出して急に失速するシャトル。クリア / ドロップ / スマッシュ | 5点先取・1人1回で返す |
| フェンシング | 中央線を挟んだ間合いの読み合い。突き（踏み込み）とパリィ | 5点先取・同時の突きは相打ち |
| ボクシング | 移動・ガード・パンチ。振りかぶりに合わせるとカウンター | KO、または60秒後に有効打の多い方 |

仕様は [SPECIFICATION.md](SPECIFICATION.md) を参照してください。

## 必要なもの

- 遊ぶ: macOS 12 以降（Intel / Apple シリコン）、または Windows 10 / 11（x64）
- 作る: Flutter 3.41 以降
  - Mac 版: Mac + Xcode
  - Windows 版: Windows + Visual Studio 2022（「C++ によるデスクトップ開発」）

サーバー・アカウント・APIキーは不要です。

## ビルドと起動

```sh
flutter pub get
flutter run -d macos        # Mac で開発用に起動
flutter run -d windows      # Windows で開発用に起動
```

配布用のビルド:

```sh
./tool/build_macos.sh       # Mac: build/macos/Build/Products/Release/PONG!.app（x86_64 + arm64）
flutter build windows       # Windows（Windows 上で実行）: build/windows/x64/runner/Release/ のフォルダごと配る
```

GitHub に push すると `.github/workflows/build.yml` がテストを走らせ、Windows 版と Mac 版をビルドして Artifacts に置きます（Windows 機がなくても Windows 版を作れます）。

> Xcode 27 の `lipo` には、複数のアーキテクチャをまとめて確かめる `-verify_arch arm64 x86_64` が失敗する不具合があり、Flutter の macOS ビルドがこれで止まります。
> `tool/lipo-shim/lipo` が1つずつ確かめる形に直して本物の `lipo` に渡すようにしてあり、Xcode のビルドスクリプト（`macos/Runner.xcodeproj` と `Runner.xcscheme`）から使っています。古い Xcode でも害はありません。

### 初回起動時の許可

- **Mac**: 「ローカルネットワーク上のデバイスを検索」の許可を求められたら「許可」。拒否した場合は システム設定 →「プライバシーとセキュリティ」→「ローカルネットワーク」で PONG! をオンに。
  署名なしのビルドを別の Mac にコピーした場合は、初回だけ右クリック →「開く」。
- **Windows**: 「Windows セキュリティの重要な警告（ファイアウォール）」が出たら、**プライベート ネットワーク**へのアクセスを許可してください。許可しないと相手のPCから見つけてもらえません。
  Wi-Fi のネットワークの種類が「パブリック」になっていると届かないことがあるので、家庭や学校の Wi-Fi は「プライベート」にしておくと確実です。

## 2台で遊ぶ

1. 2台のPCを**同じWi-Fi**につなぎ、両方で PONG! を開く。
2. 遊ぶゲームを選び、片方が **部屋を作る**（作った人が左の選手）。
3. 相手を呼ぶ方法は3つ:
   - **紙飛行機で招待**: 相手のPCを右どなりに置き、部屋の画面の「招待を送る」を押す。紙飛行機が画面の右端から飛び出し、相手の画面の左端の同じ高さから入ってきて招待状になる。相手は「参加する」を押すだけ。
   - **部屋コード**: 画面の4文字のコードを伝え、相手が「コードで参加」に入力する。
   - **近くの部屋**: 相手の対戦準備画面に「近くで相手を待っている部屋」として出るので、「参加する」を押す。
4. 2人とも **準備OK** → 操作説明とカウントダウンのあと試合開始。
5. 試合後は **もう一度**（2人とも押すと再戦）か **タイトルへ**。

設定画面で名前と棒人間の見た目（あたま・かお・かみ/ぼうし・ポーズ）を変えられます。部屋や招待状に表示されます。

### 操作（2台とも同じキー・各自のキーボード）

| キー | バレー | バドミントン | フェンシング | ボクシング |
| --- | --- | --- | --- | --- |
| A / D | 左右に移動 | 左右に移動 | 前後に移動 | 左右に移動 |
| Space | ジャンプ | ジャンプ | パリィ | ガード（長押し） |
| J | 打つ（後ろ+J でトス、ジャンプ中の高い打点でスパイク） | 打つ（前+J ドロップ / 後ろ+J クリア / ジャンプ中の高い打点でスマッシュ） | 突き | パンチ |

キーは物理的な位置で読むので、日本語入力やキー配列に関係なく動きます。試合画面にいる間だけゲーム操作として受け取ります。

### 切断と再接続

- 試合中に通信が切れると試合は**一時停止**し、両方の画面に状態が出ます。
- 参加した側は自動でつなぎ直し、つながると **3秒のカウントダウン後に同じ状態から再開** します。
- 60秒以内に戻れなければ退出扱いになり、部屋を作った人は部屋に残って新しい相手を待つかタイトルへ戻れます。参加した側には理由とタイトルへ戻るボタンが出ます。

## しくみ

- **見つけ方（サーバーなし）**: 各PCが1秒ごとに UDP ブロードキャスト（ポート 47521）で「名前・アバター・状態（待機中 / 部屋あり / 満員 / 試合中）・部屋コード・TCP の待ち受けポート」を知らせ合います。部屋コードでの参加、近くの部屋の一覧、紙飛行機の招待先の一覧はすべてここから作ります。Dart 標準のソケットだけなので Mac と Windows で同じに動きます。
- **つなぎ方**: PC 同士を TCP で直接つなぎます。メッセージは「4バイトの長さ + JSON」。1秒ごとの ping と、試合中は3秒無通信で切断とみなす生存確認つき。
- **ホストが権威**: 部屋を作ったPCだけが 60Hz の固定ステップで試合を計算し、毎フレームの状態を相手に送ります。相手は入力を送って届いた状態を描くだけなので、二重得点や画面ごとの食い違いが起きません。
- **入力**: 押しっぱなしは状態、連打は通算の押下回数で送り、ホストが差分で「押した瞬間」を数えます。通信の間隔に関係なく連打を取りこぼしません。

## ディレクトリ構成

```
lib/
  main.dart              起動とテーマ（スマホ版と同じ）
  app/                   AppModel（画面の流れ・招待）、キーボード、設定、効果音
  ui/                    スマホ版のデザイン部品（doodle.dart, widgets.dart）+ ロゴ・キーの形
  avatar/                スマホ版の棒人間アバター（見た目・編集）
  games/core/            共通: 座標系・入力・試合進行（MatchEngine）・収録タイトル（catalog）・描画の部品
  games/rally/           ネット競技の共通ルールと描画（サーブ・ネット・イン/アウト・タッチ数）
  games/volley|badminton|fencing|boxing/   競技ごとのルールと描画
  net/                   wire（メッセージ）、link（TCP）、discovery（UDP で近くのPCを探す）、sessions（ホスト / ゲスト）
  screens/               画面（ホーム・対戦準備・部屋と招待・試合と結果・あそびかた・設定・紙飛行機）
assets/                  Yomogi フォント（OFL）、効果音
macos/ windows/          各OSの起動部分（ウィンドウの大きさ、アイコン、Mac のネットワーク権限）
tool/                    Mac 版のビルドスクリプトと lipo の不具合よけ
test/                    テスト
```

### 新しいゲームを追加するには

1. `lib/games/<名前>/` に `SportRules`（ルール・物理、状態は `GameWorld`）と `SportPainter`（描画）を書く。
2. `GameKind`（`lib/games/core/catalog.dart`）に値を1つ足し、ルール・描画・説明・操作を返す。

メニュー、部屋、招待、接続状態、スコア表示、結果画面はそのまま共通で使えます。

## テスト

```sh
flutter test
```

- `game_test.dart`: 4タイトルをボット同士で決着まで（途中の状態の送受信も確認）/ バレーの得点とサーブ交代 / 連打の数え方 / 通信フレームの分割・結合 / 部屋コード
- `network_test.dart`: 実際の TCP（このPCの中のループバック）でホストとゲストをつなぎ、部屋コード参加（存在しない・満員も）→ 準備完了 → 試合 → 両者の状態が tick ごとに一致 → 入力の反映 → 切断で一時停止 → 自動再接続で同じ状態から再開 → 退出。部屋を閉じたときのゲスト側の終了、紙飛行機の招待で参加、UDP のお知らせで2つの PONG! がお互いを見つけること
- `widget_test.dart`: 相手が参加すると部屋の画面が更新されること
- `screenshot_test.dart`（任意）: `SNAPSHOT_DIR=/path/to/dir flutter test test/screenshot_test.dart` で各画面を PNG に書き出します
